## 前提条件

:::caution[Node.js v22 以降が必要]
Purus **v1.x** は **Node.js v22 以降** が必要です。それ以前のバージョンはサポートされていません。
:::

以下のいずれかから Node.js をインストールしてください:

- [Node.js v22](https://nodejs.org/ja/download/releases) — v22 各リリース
- [Node.js LTS](https://nodejs.org/en/download) — 最新 LTS リリース
- [nvm](https://github.com/nvm-sh/nvm) *(推奨)* — Node Version Manager（macOS / Linux）
- [nvm-windows](https://github.com/coreybutler/nvm-windows) *(推奨)* — Node Version Manager（Windows）

:::tip[nvm を使う場合]
```sh
# Node.js v22 をインストールして使用
nvm install 22
nvm use 22

# または最新 LTS をインストールして使用
nvm install --lts
nvm use --lts
```
:::

## npmでインストール

最新バージョン: <NpmVersion package="purus" /> — [npmで見る](https://www.npmjs.com/package/purus)

```sh
npm install -g purus
```

## 動作確認

```sh
purus version
```

## はじめてのプログラム

`main.purus` ファイルを作成:

```purus
const message be //;Hello, World;//
console.log[message]
```

コンパイルして実行:

```sh
purus build main.purus
node main.js
```

またはファイルを生成せず直接実行:

```sh
purus run main.purus
```

## プロジェクトの作成

`purus new` で設定・スクリプト・依存関係を含むプロジェクトをセットアップ:

```sh
purus new my-project
cd my-project
npm run build
```

## ファイル拡張子

| 拡張子 | 出力 | 用途 |
|---|---|---|
| `.purus` | `.js` | 標準 JavaScript |
| `.cpurus` | `.cjs` | CommonJS モジュール |
| `.mpurus` | `.mjs` | ES モジュール |
