# Contributing to Purus Docs

Thank you for your interest in contributing!

[日本語版はこちら](https://github.com/puruslang/docs/blob/main/CONTRIBUTING-ja.md)

## About

Documentation site for Purus — deployed at purus.work.

## Prerequisites

- [Node.js](https://nodejs.org/) >= 22
- [Git](https://git-scm.com/)

## Getting Started

```sh
git clone https://github.com/puruslang/docs.git
cd docs
npm install
npm run dev
```

## Development

| Command | Description |
|---|---|
| `npm run dev` | Dev server (localhost:4321) |
| `npm run build` | Production build |

## Submitting Pull Requests

1. Fork the repository and create a branch from `main`
2. Make your changes
3. Run tests and ensure they pass
4. Open a PR with a clear description

## Release

Releases are triggered by pushing a `v*` tag (e.g., `v1.1.0`).
